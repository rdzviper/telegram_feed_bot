# is_ad: реальные тест-кейсы (нативная/скрытая реклама + контроли)

Золотой сет для правила `is_ad` в `analyzer.py`. Собран из боевого потока
17.07.2026: три нативки, которые старый промт пропускал (`is_ad=false`), плюс
контроли — реальные новости, которые НЕ должны помечаться рекламой.

Прогонялка: `python -m scripts.try_is_ad` (temperature=0, сравнивает старый и
новый промт). Проверялось на `deepseek-v4-flash`.

Легенда:
- `[native]` — скрытая реклама без явного «купи», подана как новость. Должна ловиться.
- `[control]` — настоящая новость о компании/продукте. Должна остаться `is_ad=false`.

Ожидание: новый промт даёт 6/6 (все native → true, все control → false).

---

## AD1 — МТС Накопления `[native]` → is_ad=true
Признак: само-отчётная метрика бренда как «новость», внешне значимого события нет.
```
Россияне активнее инвестируют. Сервис «МТС Накопления» рассказал об увеличении
объёма вложенных клиентами средств в 4,3 раза по итогам первого полугодия. Число
открытых счетов тоже увеличилось — более чем вдвое. При этом 9% из них открыты
пользователями, которые не являются абонентами МТС. rozetked.me/news/47250
```

## AD2 — Т-Банк, Кубок T-Private `[native]` → is_ad=true
Признак: освещение брендового ивента в выгодном свете + PR-цитата компании.
```
Т-Банк провел второй закрытый теннисный турнир «Кубок T-Private» для своих
состоятельных клиентов... В Т-Банке подчеркнули, что в направлении private-banking
растет интерес не только к теннису, но и к здоровому образу жизни, поэтому сервис
дополняют партнерствами, привилегиями и мероприятиями в сфере wellness.
```

## AD3 — Antarctic Wallet `[native]` → is_ad=true
Признак: анонс фичи + реферальный деплинк на бота (`startapp=ref_…`).
```
В Antarctic Wallet (t.me/antarctic_wallet_bot/app?startapp=ref_15a51e7fd9)
появилась возможность выпускать виртуальные карты для оплаты покупок. Теперь можно
оплачивать любые покупки через Мir Pay и QR коды с использованием USDT.
```

## CTRL1 — запуск PS5 Pro `[control]` → is_ad=false
Настоящий продуктовый анонс с новостной ценностью. Не реклама.
```
Sony официально представила PlayStation 5 Pro на презентации State of Play.
Консоль получила более мощный GPU и апскейлер PSSR. Старт продаж 7 ноября, цена 700$.
```

## CTRL2 — отзыв лицензии ЦБ `[control]` → is_ad=false
Событие/регулятор, критический угол.
```
ЦБ отозвал лицензию у банка «Пример» из-за систематических нарушений
антиотмывочного законодательства и утраты капитала. Вкладчики получат выплаты через АСВ.
```

## CTRL3 — штраф МТС за утечку `[control]` → is_ad=false
Негативная новость про тот же бренд (МТС) — защита от ложного срабатывания.
```
МТС оштрафовали на 5 млн рублей за утечку персональных данных абонентов.
Роскомнадзор зафиксировал нарушение при обработке данных.
```
