# is_ad: реальные тест-кейсы (нативная/скрытая реклама + контроли)

Золотой сет для правила `is_ad` в `analyzer.py`. Собран из боевого потока:
17.07.2026 — три нативки, которые старый промт пропускал (`is_ad=false`);
29.07.2026 — сбор пожертвований (приют «КирЮшка», AD4): промт с правилом
только про бренды/продукты его пропускал. Плюс контроли — реальные новости,
которые НЕ должны помечаться рекламой.

Прогонялка: `python -m scripts.try_is_ad` — гоняет ТЕКУЩИЙ промт через
`analyzer.analyze` (прод-путь: короткие посты без DeepSeek, обрезка text[:1500]).
Проверялось на `deepseek-v4-flash`, temperature=0.

Легенда:
- `[native]` — скрытая реклама без явного «купи», подана как новость. Должна ловиться.
- `[control]` — настоящая новость о компании/продукте. Должна остаться `is_ad=false`.

Ожидание: 8/8 (все native → true, все control → false).

## AD1 — МТС Накопления `[native]` → is_ad=true
Признак: само-отчётная метрика бренда как «новость», внешне значимого события нет.
```

объёма вложенных клиентами средств в 4,3 раза по итогам первого полугодия. Число
открытых счетов тоже увеличилось — более чем вдвое. При этом 9% из них открыты
пользователями, которые не являются абонентами МТС. rozetked.me/news/47250
```

Признак: освещение брендового ивента в выгодном свете + PR-цитата компании.
```
Т-Банк провел второй закрытый теннисный турнир «Кубок T-Private» для своих
состоятельных клиентов... В Т-Банке подчеркнули, что в направлении private-banking

дополняют партнерствами, привилегиями и мероприятиями в сфере wellness.
```
