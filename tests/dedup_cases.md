# Дедуп: реальные тест-кейсы (золотой сет для калибровки порога)

Собраны из боевого потока. Используются для подбора порога дедупа
(текстовый overlap + cosine эмбеддингов). Каждый кластер = одна новость,
все посты внутри кластера ДОЛЖНЫ схлопнуться в один форвард.

Легенда:
- `[verbatim]` — побайтовый репост, обязан ловиться дешёвым текстовым слоем.
- `[semantic]` — та же новость другими словами, нужны вектора (концепт-overlap ≈ 0).

## Ожидаемое поведение

| Пара | Как должно ловиться |
|------|---------------------|
| 1a↔1b, 2a↔2b | текстовый слой (overlap ≈ 1.0) |
| 1a↔1c, 2a↔2c | вектора (cosine ≥ порог); текст и концепты недостаточны |

Целевой порог cosine подбирать так, чтобы все `[semantic]` пары попадали в дубли,
но разные новости того же дня (напр. Минцифры vs Wildberries) — нет.
